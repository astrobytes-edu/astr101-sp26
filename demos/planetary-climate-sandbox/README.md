# Planetary Climate Sandbox

Student demo: `demos/planetary-climate-sandbox/`

## What this is

A static (no build step) demo for Lecture 12 that lets students explore a simple, honest planetary energy-balance model plus a calibratable toy greenhouse parameter.

## Files

- `index.html` — demo UI (works when opened as a local file)
- `planetary-climate-sandbox.css` — demo styling
- `planetary-climate-sandbox.js` — UI logic + rendering
- Model (shared + unit-tested): `demos/_assets/planetary-climate-model.js`
- Presets dataset (no fetch): `demos/_assets/climate/planet-presets.v1.js`
