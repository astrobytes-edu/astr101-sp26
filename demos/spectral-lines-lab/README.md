# Spectral Lines Lab

Interactive teaching demo for ASTR 101 Lecture 9: Kirchhoff’s laws and spectral fingerprints.

## Teaching goals

- Practice the three spectrum types (continuous / emission / absorption) via Kirchhoff-style setups.
- Build the idea of “element fingerprints” as **patterns** of lines.
- Prepare students to treat lines as trackable features for Doppler shifts in Lecture 10.

## Data integrity

This demo uses the shared spectra datasets:

- `demos/_assets/spectra/atomic-lines.v1.json` (canonical)
- `demos/_assets/spectra/molecular-bands.v1.json` (canonical; optional IR mode)
- `demos/_assets/spectra/spectra-data.v1.js` (browser bundle)

Data rules are specified in `docs/contracts/spectra-data-contract.md`.
