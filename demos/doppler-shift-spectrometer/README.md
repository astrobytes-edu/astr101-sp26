# Doppler Shift Spectrometer

Interactive teaching demo for ASTR 101 Lecture 10: Doppler shifts and radial velocity.

## Core idea

Students compare a rest spectrum to an observed spectrum and measure a shift:

$$\\Delta\\lambda = \\lambda_{\\text{obs}} - \\lambda_0$$

Then use:

$$\\frac{\\Delta\\lambda}{\\lambda_0} = \\frac{v}{c}$$

with the correct sign convention (positive = receding = redshift).
