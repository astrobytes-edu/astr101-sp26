## Hard Invariants (Non-Negotiable)

### Scientific correctness / misconception resistance

- Kepler I: Never place the Sun at the **center** of an ellipse; it must be at a **focus**.
- Kepler II: If we depict “equal areas,” they must be equal **by construction** (no “close enough” wedges).
- Newton’s cannon: “Orbit = falling while moving sideways” must be visually unmistakable; avoid implying thrust is required to “keep going.”
- Acceleration in circular motion: velocity vectors tangent; acceleration vector inward; avoid implying “acceleration = speeding up.”
- Inverse-square: explicitly connect to spherical area growth; avoid implying force “uses up” or “runs out.”
- Free fall: emphasize “weight = normal force” and “microgravity ≠ zero gravity.”

### Figure system contracts

- Every figure used in readings is registered in `assets/figures.yml` with `path`, `caption`, `alt`, and `credit`.
- Readings embed figures only via `{{< fig figure-id >}}` (no raw asset paths).
- SVG must include accessible metadata: `<svg ... role="img" aria-labelledby="title desc">`, plus `<title>` and `<desc>`.

### Theme / style contracts

- Semantic mapping: teal = primary structure; pink = teaching target; violet = secondary guides.
- Use the repo template tokens (`var(--teal)`, `var(--pink)`, `var(--violet)` etc.) so exports can be baked reliably.
- Keep strokes and arrowheads subtle; avoid “clip-art” aesthetics.
- Spaced em dash rule in any prose added/edited: `word — word`.

### Reproducibility

- Export review artifacts only into `_previews/` directories (git-ignored by `assets/images/**/_previews/*.{png,pdf}`).
- Any LaTeX snippets: do not introduce accidental `\\` escapes; prefer single-backslash LaTeX inside single quotes in the shell.

## Task 1: Create L5 figure `retrograde-motion-mars` (conceptual, two-panel)

**Files:**
- Create: `assets/images/module-01/lec05/retrograde-motion-mars.svg`
- Export (git-ignored): `assets/images/module-01/lec05/_previews/retrograde-motion-mars.pdf`

**Step 1: Scaffold from template**

- Copy `assets/images/module-01/_svg-template.svg` → `assets/images/module-01/lec05/retrograde-motion-mars.svg`.
- Set `<title>` and `<desc>` to match the figure intent.
- Set header title/subtitle to something like:
  - Title: “Retrograde motion is an illusion”
  - Subtitle: “Earth passes Mars — the line of sight changes.”

**Step 2: Build panel layout (professional, not busy)**

- Left panel (sky view): faint starfield + plotted Mars points connected by a line that makes a clear “loop”; highlight the retrograde segment in pink.
- Right panel (top-down orbits): simple circular orbits for Earth and Mars with arrows; show Earth overtaking Mars; draw 2–3 line-of-sight rays to Mars at key moments.

- Use violet for guide rays; pink for the “teaching target” loop segment.

**Step 4: Export previews (PDF-first)**

Run:

```bash
conda run -n astro python scripts/render_svg_to_png.py assets/images/module-01/lec05/retrograde-motion-mars.svg assets/images/module-01/lec05/_previews/retrograde-motion-mars.pdf --format pdf --width 1800 --theme dark --palette aurora

```

Expected: both files created; colors match palette; labels legible at ~50% scale.

**Step 5: Quality gate**

- No label overlaps at 960×540.
- Starfield stays subtle (do not compete with the loop).
