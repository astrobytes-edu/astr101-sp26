# Homework 7 Design

**Date:** 2026-05-01

**Goal:** Build a final Module 3 homework that works as both final-exam rehearsal and a cosmology evidence-chain capstone.

## Recommended structure

Use a **Cosmic Evidence Arc**:

1. map hidden mass in galaxies,
2. read galaxies and active galactic nuclei as physical systems,
3. climb the cosmic distance ladder,
4. use standard candles and redshift to infer cosmic expansion,
5. close with one explicit Observable -> Model -> Inference evidence chain.

This keeps the assignment from becoming five disconnected lecture checklists while still giving students concrete final-exam practice.

## Why this set works

- It includes all five Module 3 readings.
- It balances conceptual classification, calculation, and synthesis.
- It repeatedly asks students to separate observables from inferred physical claims.
- It rehearses final-exam tools: rotation curves, luminosity from flux and distance, distance-ladder calibration, Hubble's law, standard candles, and CMB redshift scaling.
- It ends with a student-chosen capstone claim: dark matter, dark energy, the Big Bang, the CMB, or the origin of the elements.

## Difficulty profile

- Early problems: galaxy evidence and hidden mass.
- Middle problems: distance and luminosity calculations.
- Late problems: expansion-history interpretation.
- Final problem: synthesis and transfer.
